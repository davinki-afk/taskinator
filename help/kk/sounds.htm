Өз дыбыстарыңыз

  1. Taskinator.exe орналасқан қалтаны ашыңыз. Оның жанындағы sounds қалтасында дыбыс жинағыңызға арналған ішкі қалта жасаңыз, мысалы, sounds\MySounds.
  2. Кестедегі атауларды пайдаланып, WAV файлдарын сол ішкі қалтаға салыңыз.
  3. Taskinator бағдарламасында «Баптаулар» → «Дыбыстар» бөлімін ашып, «Тізімді жаңарту» түймесін басыңыз. «Дыбыс қалтасы» тізімінен өз қалтаңызды таңдап, «ОК» түймесін басыңыз.
Файл атауыҚай кезде ойнатылады
taskcomplete.wavТапсырма аяқталған деп белгіленгенде
reminder.wavАлдын ала еске салу іске қосылғанда
alarm.wavБелгіленген еске салу уақыты келгенде

Үш дыбыстың кез келгенін ауыстыруға болады. Қажетті файл жинағыңызда болмаса немесе ойнатылмаса, Taskinator sounds\default қалтасындағы тиісті файлды ойнатып көреді.

Taskinator Program Files қалтасына орнатылса, файлдарды көшіру үшін Windows әкімші рұқсатын сұрауы мүмкін.
