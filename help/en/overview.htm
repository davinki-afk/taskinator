Taskinator features

Lists and tasks

Use the buttons below the “My lists” panel to create, rename, or delete lists. You can choose an icon for each list. Select a list and click “+” above the task panel to add a task.

In the task editor, you can add a description, subtasks, and tags, and choose a title color. Mark tasks as complete or incomplete directly in the list. Completed tasks appear in the “Completed tasks” section.

Drag lists or tasks to change their order. To move a task to another list, drop it on the list name or choose “Move to list” from the context menu.

Search and reminders

The “Search” button searches all lists. Enter the title or description of a task or subtask, or the name of a tag. You can set a date range for reminders and hide completed tasks.

Set the reminder date and time in the task editor. Turn on “Remind me early” if you want an extra alert before the scheduled time. When you close the main window, Taskinator stays in the notification area and continues to show reminders. To quit, choose “Exit” from the menu on its notification area icon.

Settings and saving data

In Settings, you can manage tags and change the language, theme, task count, keyboard shortcuts, or sound pack.

Taskinator saves your data automatically to %APPDATA%\Taskinator\lists.xml. Under “Settings” → “Import and export”, you can export your lists to a CSV or XML file and import them from a file. Click “OK” to apply the import.
