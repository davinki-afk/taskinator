Власні звуки

  1. Відкрийте папку, у якій міститься Taskinator.exe. У папці sounds поруч із ним створіть підпапку для свого набору звуків, наприклад sounds\MySounds.
  2. Помістіть до цієї підпапки WAV-файли з назвами, наведеними в таблиці.
  3. У Taskinator відкрийте «Налаштування» → «Звуки», натисніть «Оновити список», виберіть свою папку у списку «Папка зі звуками» та натисніть «ОК».
Назва файлуКоли лунає
taskcomplete.wavКоли завдання позначено як виконане
reminder.wavКоли спрацьовує завчасне нагадування
alarm.wavКоли настає призначений час нагадування

Можна замінити будь-який із трьох звуків. Якщо потрібного файлу немає у вашому наборі або він не відтворюється, Taskinator спробує використати відповідний файл із папки sounds\default.

Якщо Taskinator установлено в Program Files, Windows може запитати дозвіл адміністратора під час копіювання файлів.
