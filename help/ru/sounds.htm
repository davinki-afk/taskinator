Свои звуки

  1. Откройте папку, где находится Taskinator.exe. В каталоге sounds рядом с ним создайте подпапку для своего набора, например sounds\MySounds.
  2. Положите в эту подпапку файлы в формате WAV с именами из таблицы.
  3. В Taskinator откройте «Настройки» → «Звуки», нажмите «Обновить список», выберите свою папку из списка «Папка со звуками» и нажмите «ОК».
Имя файлаКогда звучит
taskcomplete.wavКогда задача отмечена выполненной
reminder.wavКогда срабатывает заблаговременное напоминание
alarm.wavКогда наступает назначенное время напоминания

Можно заменить один звук, несколько или все три. Если нужного файла нет в вашем наборе или он не воспроизводится, Taskinator попробует использовать соответствующий файл из sounds\default.

Если Taskinator установлен в Program Files, Windows может запросить права администратора при копировании файлов.
