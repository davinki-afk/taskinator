# Taskinator

Taskinator — настольный менеджер задач для Windows. В нём можно вести несколько списков дел, разбивать задачи на шаги и получать напоминания в области уведомлений Windows. Списки, задачи и настройки сохраняются локально в профиле пользователя.

## Списки и задачи

1. Создайте список кнопкой «+» под панелью «Мои списки». Списку можно назначить значок, а затем переименовать его или изменить порядок списков перетаскиванием.
2. Выберите список и нажмите «+» над панелью задач или `Ctrl+N`. В редакторе задайте название, добавьте описание, подзадачи и цветные теги. Для названия можно выбрать цвет, а для каждой подзадачи — добавить описание и отдельно отметить её выполнение.
3. Отмечайте задачи флажками прямо в списке. Выполненные задачи собираются в сворачиваемом разделе, откуда их можно вернуть в работу или удалить. Перетаскивайте задачи внутри списка для изменения порядка или на название другого списка для переноса. Перенос также доступен через контекстное меню.

Представления **«Все задачи»** и **«Выполненные задачи»** объединяют задачи из всех списков. **«На сегодня»** и **«На неделю»** показывают задачи с напоминаниями, назначенными на текущий день или календарную неделю с понедельника по воскресенье по местному времени.

Откройте **«Поиск»** (`Ctrl+F`), чтобы найти задачу по названию, описанию или тегу, а подзадачу — по названию или описанию. Результаты можно ограничить диапазоном дат напоминаний и скрыть выполненные пункты. Из результата можно перейти к задаче или подзадаче в её списке.

## Напоминания и работа в фоне

В редакторе задачи включите напоминание и укажите дату и время. Вариант **«Напомнить заранее»** добавляет сигнал за выбранное число минут, часов или дней до назначенного времени. Taskinator показывает уведомление и воспроизводит WAV-файл. Напоминания срабатывают для незавершённых задач, пока приложение запущено, в том числе при скрытом окне. Если назначенное время прошло, пока приложение было закрыто, основное напоминание появится после запуска.

Кнопка закрытия окна оставляет Taskinator в области уведомлений. Двойной щелчок по значку открывает окно, а команда **«Выход»** в меню значка завершает работу приложения. В настройках можно включить автозапуск при входе в Windows и выбрать, показывать ли при этом главное окно.

## Настройки и данные

- **Интерфейс.** Доступны русский, английский, украинский, белорусский и казахский языки, системная тема и три цветовые схемы в стиле Office 2003. В настройках можно изменить горячие клавиши и выбрать, считать ли все задачи списка или только незавершённые.
- **Звуки.** В разделе **«Настройки» → «Звуки»** можно выбрать или импортировать папку с WAV-файлами. `taskcomplete.wav` звучит при завершении задачи, `reminder.wav` — при заблаговременном напоминании, `alarm.wav` — в назначенное время. Для отсутствующего или невоспроизводимого файла используется соответствующий звук из `sounds/default`. Звук завершения задач можно отключить отдельно.
- **Хранение.** Taskinator автоматически сохраняет задачи и настройки в `%APPDATA%\Taskinator\lists.xml`. Для резервной копии задач и настроек можно скопировать этот файл.
- **Импорт и экспорт.** В разделе **«Настройки» → «Импорт и экспорт»** можно выгрузить списки, задачи, подзадачи и теги в XML или CSV в формате Taskinator. Импорт добавляет записи с новыми идентификаторами и сохраняет существующие. Чтобы применить импорт, нажмите **«ОК»**.
- **Справка.** Команда **«Помощь» → «Справка»** открывает локальное руководство CHM на языке интерфейса.

## Библиотеки и инструменты

| Компонент | Назначение |
| --- | --- |
| C# и .NET Framework 4.0 | Основное приложение. `System.Core` используется для LINQ, `System.Xml` и `XmlSerializer` — для хранения и обмена данными. CSV обрабатывается кодом проекта. |
| Windows Forms (`System.Windows.Forms`) и GDI+ (`System.Drawing`) | Окна, редакторы, значок в области уведомлений и отрисовка интерфейса. |
| Win32 API | Воспроизведение WAV через `winmm.dll` и взаимодействие с Windows, включая активацию уже запущенного окна. |
| Win32++ 9.6.1 | Необязательная библиотека C++ для градиента панели инструментов. Заголовки и лицензия входят в проект. На Windows 7 и новее используется DLL подходящей разрядности, если она доступна. В остальных случаях градиент рисует GDI+. [Описание нативного модуля](Taskinator/native/README.md) |
| Microsoft HTML Help Workshop и Inno Setup | Компиляция справки CHM и упаковка установщика соответственно. |

Основное приложение использует стандартные сборки .NET Framework. Устанавливать пакеты NuGet для сборки не требуется.

## Сборка и запуск

Для запуска нужна полная версия **.NET Framework 4.0** или более новая версия **4.x**. Для Windows XP SP3 используйте сборку без нативного модуля Win32++.

### Сборка приложения

На Windows установите MSBuild, компилятор C# и средства разработки для **.NET Framework 4.0** с эталонными сборками (например, Visual Studio 2010). Откройте [Taskinator.sln](Taskinator.sln) и соберите конфигурацию `Release` или выполните из папки с решением в командной строке разработчика Visual Studio:

```bat
msbuild Taskinator\Taskinator.csproj /p:Configuration=Release /p:Platform=AnyCPU /p:BuildWin32xxTheme=false
```

Запустите `Taskinator\bin\Release\Taskinator.exe`. Для отладочной сборки замените `Release` на `Debug`. При переносе копируйте весь выходной каталог, чтобы рядом с EXE остались папки `icons`, `lang`, `sounds` и `help`. Готовые файлы CHM копируются автоматически. Если изменили исходники справки, пересоберите `Taskinator.hhp` для нужного языка в HTML Help Workshop перед сборкой приложения.

### Сборка с Win32++

Для нативного модуля также нужны инструменты сборки C++ для x86 и x64 и Windows SDK. В командной строке разработчика Visual Studio запустите:

```bat
msbuild Taskinator\Taskinator.csproj /p:Configuration=Release /p:Platform=AnyCPU /p:BuildWin32xxTheme=true
```

В выходном каталоге появятся `Win32xxTheme.x86.dll`, `Win32xxTheme.x64.dll` и `Win32xx-License.txt`.

### Сборка установщика

Соберите приложение в конфигурации `Release`. Откройте командную строку в папке с `Taskinator.csproj` и обновите папку `Taskinator`, из которой сценарий установщика берёт файлы приложения. Запустите компилятор **Inno Setup 5.6.1 (Unicode)**, указав полный путь к `ISCC.exe`, если он отсутствует в `PATH`.

```bat
xcopy bin\Release Taskinator /E /I /Y
ISCC.exe Taskinator.iss
```

Установщик появится в `Output\Taskinator-Setup.exe`. Сценарий включает EXE, значки, переводы, стандартные звуки и CHM. Сборку с DLL Win32++ можно распространять целиком из выходного каталога MSBuild.
